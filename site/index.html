Questions

Which PCs can run ArmCheck?

ArmCheck is built for Windows 11 on ARM64. It uses Microsoft Edge WebView2 for its desktop interface.

Why can’t ArmCheck verify some apps?

Windows restricts access to some processes. Files that use hybrid ARM formats or give conflicting architecture evidence also need an unverified label.

Where does the scan run?

The desktop app scans locally on your PC. It doesn’t upload your running apps or executable paths.
