# Changelog

## 0.1.0

First public release for Windows 11 on ARM64.

- Shows native, emulated, mixed, and unverified running apps with Windows evidence.
- Adds desktop and full-process views, search, sorting, architecture filters, and verification-reason filters.
- Checks executable and installer files on disk through drag and drop, the file picker, or the CLI.
- Samples CPU and working-set RAM while the main window is visible and pauses when minimized or hidden to the tray.
- Includes the native ARM64 desktop executable, an NSIS installer, and SHA-256 checksums.
